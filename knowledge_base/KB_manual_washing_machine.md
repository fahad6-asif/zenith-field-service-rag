# Zenith AquaWash Front-Load Washing Machine — Service Manual (extract)

**Model:** ZWM-70FL (7 kg, 1200 rpm)
**Document:** User & Service Manual, Rev. 2023-09

## Error codes
| Code | Meaning |
|------|---------|
| F1 | Water inlet fault (no / low water supply) |
| F2 | Drainage fault (pump blocked or drain hose kinked) |
| F3 | Door-lock fault |
| F4 | Water-heater overheating |
| F5 | Unbalanced load / excessive vibration |
| F6 | Motor / tacho sensor fault |
| F8 | Water leak detected (Aquastop triggered) |

## Troubleshooting
- **F2 — not draining:** clean the pump filter behind the small hatch at the bottom-front, and check the drain hose for kinks. **Unplug the machine before opening the pump filter.**
- **F3 — door won't open:** there may still be water in the drum, or the door-lock is on its safety delay. Run a drain/spin program and wait ~2 minutes after the cycle ends.
- **F4 — water-heater overheating:** switch the machine off, allow it to cool for about 30 minutes, then restart the cycle. If F4 recurs, contact service.
- **F5 — excessive vibration / won't spin:** redistribute the load, make sure the machine is level, and confirm the transit bolts were removed at installation.
- **Not spinning:** most often **F5** (unbalanced load) or **F2** (water not drained).

## Safety
- Always unplug the machine before clearing the pump filter.
- If **F8 (leak)** appears, turn off the water tap and call a technician — do not keep running the machine.
