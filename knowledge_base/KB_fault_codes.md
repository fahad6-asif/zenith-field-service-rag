# Zenith Fault-Code Reference (all products)

> Note: air conditioners use **E-codes**; washing machines use **F-codes**. A similar number on a different product means a different thing (e.g. E5 vs F5).

## Split AC (ZAC-12INV / ZAC-18INV)
| Code | Meaning | First action |
|------|---------|--------------|
| E1 | Indoor temperature sensor fault | Technician check |
| E2 | Outdoor communication failure | Technician check |
| E3 | Refrigerant leak (low pressure) | Do NOT recharge; certified technician |
| E4 | Compressor overload / high current | Power off; technician |
| E5 | Indoor fan motor fault | Technician check |
| E6 | Outdoor high-pressure protection | Clean/clear outdoor unit; if recurring, technician |

## Washing machine (ZWM-70FL)
| Code | Meaning | First action |
|------|---------|--------------|
| F1 | Water inlet fault | Check tap/supply |
| F2 | Drainage fault | Clean pump filter; check hose |
| F3 | Door-lock fault | Drain, wait 2 min |
| F4 | Heater overheating | See manual / safety bulletin SB-2026-03 |
| F5 | Unbalanced load / vibration | Redistribute load; level machine |
| F6 | Motor / tacho fault | Technician check |
| F8 | Leak detected (Aquastop) | Turn off tap; technician |
